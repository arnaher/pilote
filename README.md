Pilot PWA (React + Vite) - prêt pour GitHub Pages



Instructions pour l'utilisateur novice :

1\. Dézippe ce dossier.

2\. Sur GitHub, crée un nouveau repository vide.

3\. Dans GitHub, clique sur Add file -> Upload files et glisse tout le contenu du dossier (TOUS les fichiers, à la racine).

4\. Commit.

5\. GitHub va lancer le workflow Actions. Quand il est vert, ton site est publié à https://TON-USERNAME.github.io/NOM-REPO/
